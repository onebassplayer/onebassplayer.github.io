Who operates this planner

This Exit Planner is operated by Moonshot Consulting. For privacy questions or to request deletion, email info@moonshotconsultingdc.com.

What you enter

Quick Plan: first name and email, employment situation and notes, accessible savings, monthly essential expenses, business-idea testing and notes, skills and experience, confidence, weekly time, and constraints.

Deep Dive: an email field and a free-text conversation. The email address is included in the submission email; it is not included in the AI planning request.

Free-text answers can contain sensitive career or financial details. Share only what you are comfortable including.

How the information moves

For Quick Plan, the page sends your first name, email, and assessment answers to Moonshot’s planning service hosted by Render. For Deep Dive, it sends the conversation transcript to that service; the email field is not included in the AI planning request.

If you check the optional consent box before submitting either path, the page also sends the full submission—including the contact email and all Quick Plan answers or the full Deep Dive conversation—to the Render service for delivery to david@moonshotconsultingdc.com. The service is designed to send it using an SMTP provider configured by Moonshot Consulting. That provider has not yet been selected or configured in production. If email delivery is unavailable, you can clear the box and still request your plan without emailing Moonshot a copy.

The currently published page sends the model identifier claude-opus-4-5, which the proxy rejects before it reaches Anthropic; the browser then generates a fallback plan. This was reproduced on September 24, 2026 using synthetic text, not personal information. The unpublished website draft selects a model identifier accepted by the proxy. A synthetic request with that identifier reached Anthropic but received a 401 authentication_error because the service API key was reported invalid. This does not confirm a successful AI-generated plan. The provider credentials must be corrected and the deployed planner flow retested before this notice is approved.

The generated plan is displayed in your browser; the email feature sends the submission, not the generated plan. Consent to send a submission does not subscribe you to marketing email.

Storage, retention, and deletion

The page code reviewed does not save these answers in browser storage, and the proxy code reviewed does not write submissions to an application database. If you consent, the SMTP provider processes the message and a copy is delivered to the recipient mailbox. The provider’s and mailbox’s access, security, and retention settings have not been verified. Render or AI-provider logs may also be subject to their service settings.

The unpublished proxy draft adds shared rate limiting using a Redis-compatible service. Its keys contain a SHA-256 fingerprint of the resolved client IP and expire with the applicable rate-limit window (up to one hour); raw answer or submission content is not written to that store. These limits will not be active until the shared store and trusted Render proxy-hop setting are configured. Application error logs avoid recording prompts and submission contents, but Render access-log and Anthropic account retention settings remain outside the code and have not been verified.

No retention period or working deletion-request process has been verified. This notice must not promise a storage period, deletion outcome, or security control until those details are checked and approved.

Email and follow-up

The optional submission checkbox authorizes emailing the full submission to Moonshot Consulting at david@moonshotconsultingdc.com. You can leave it unchecked and still request a plan. It does not subscribe you to marketing emails, and the page does not call Mailchimp for this submission.

Email delivery requires SMTP environment settings on the Render service. No SMTP provider or production credentials are configured by this draft; credentials must be stored only in the service’s private environment settings, never in the webpage or source control.
